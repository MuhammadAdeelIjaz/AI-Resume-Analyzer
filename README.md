# 📄 AI Resume Analyzer

An AI-powered Resume Analyzer built with Python, Streamlit, and Groq.

The application compares a candidate's resume against a specific job
description and provides:

- Overall match score
- Matching skills
- Partial matches
- Missing skills
- ATS keywords
- Resume problems
- Recommendations
- Strengths
- Gaps
- Final verdict
- Structured JSON analysis
